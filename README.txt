StudentToolBox starter website

Files:
- index.html — responsive homepage and working browser-side tools.

Included:
CGPA to Percentage, Percentage Calculator, GPA Calculator, Word Counter,
Pomodoro Timer, Exam Countdown, Age Calculator, JPG-to-PDF placeholder,
search/filter, responsive design, About and Contact sections.

Note:
The JPG-to-PDF button is a placeholder in this starter because a PDF library
is not bundled. It can be upgraded with jsPDF or another client-side library.
Before publishing, replace the Contact placeholder, add real Privacy Policy/
Terms pages, and review monetization/AdSense requirements.
